# Voorpagina

Eigen nieuwsapp: kies je bronnen, kies per bron je onderwerpen, dubbele verhalen worden samengevoegd en *Voor jou* leert van je duimpjes.

- `sources.json`: alle bronnen en onderwerpen. Bron toevoegen = blok kopiëren.
- `scripts/fetch_news.py`: haalt feeds op, kent onderwerpen toe, groepeert dezelfde verhalen.
- `.github/workflows/nieuws.yml`: draait elk halfuur en zet de site op GitHub Pages.
- `site/`: de app (werkt als app-icoon op je iPhone via Safari → Deel → Zet op beginscherm).

Je voorkeuren en wat de app leert blijven op je eigen telefoon.
